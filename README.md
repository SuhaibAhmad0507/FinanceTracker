# Finance Tracker

A Python-based application for recording income and expenses, organizing transactions, monitoring balances, and managing personal budgets.

## Project Overview

The Finance Tracker is a semester project for the Software Construction and Development (SCD) course. It aims to provide a simple way for users to manage their personal finances and understand their spending habits.

The project will be developed incrementally using Git, GitHub, and an agile approach. Requirements and features may be refined as development progresses.

## Problem Statement

Managing personal finances manually can make it difficult to track income, identify spending patterns, maintain transaction records, and stay within a budget. The Finance Tracker aims to simplify these activities through a single application.

## Project Objectives

- Record income and expenses.
- Organize transactions into categories.
- View and search transaction history.
- Calculate the current balance and summarize spending.
- Set budgets and notify users when spending limits are exceeded.

## Initial Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | The system shall allow users to add income transactions. |
| FR-02 | The system shall allow users to add expense transactions. |
| FR-03 | The system shall allow transactions to be assigned categories. |
| FR-04 | The system shall display transaction history and support searching transactions. |
| FR-05 | The system shall calculate the current balance and display spending summaries. |
| FR-06 | The system shall allow users to set budget limits and alert them when spending exceeds a limit. |

## Non-Functional Requirements

- **Usability:** The interface should be understandable to users with basic computer skills.
- **Reliability:** The application should validate inputs and handle invalid entries appropriately.
- **Data integrity:** Transactions should be stored consistently and calculations should be accurate.
- **Maintainability:** The code should be organized into understandable functions or modules.
- **Portability:** The application should run in a compatible Python environment.

## Assumptions and Constraints

- The initial version is intended for personal finance tracking.
- Users will provide valid transaction details.
- The project will be developed using Python and standard development tools.
- Data storage will use a method selected by the team during implementation.
- The initial scope does not require integration with bank accounts or payment services.
- Authentication, cloud synchronization, and mobile applications are outside the initial scope unless later approved by the team.
